# Копайлот — история изменений

## Итог работы

Проект представляет собой iframe-фронтенд для модального окна Копайлота,
встраиваемого в SimpleOne ITSM через UI Action. Ниже описано всё, что было
сделано с нуля.

---

## Этап 1 — Редизайн MVP интерфейса

**Было:** тестовая страница с отладочной информацией — URL-параметры,
кнопки «Вставить решение» / «Закрыть модалку», textarea с тестовым текстом.
Никакого реального интерфейса Копайлота не было.

**Сделано:**

- Полностью переписан `src/main.jsx` — новый модальный UI с тремя вкладками
- Переписан `src/styles.css` — профессиональный дизайн для корпоративного ITSM

### Шапка (Header)
- Логотип + заголовок «Копайлот»
- Кнопка «Суммировать заявку»
- Кнопка закрытия (×) → отправляет `copilot.close_modal`

### Вкладка «Подсказки ИИ»
- Skeleton-лоадер (shimmer-анимация, 1 сек) перед отображением карточек
- 3 mock-карточки статей базы знаний: заголовок-ссылка, выдержка, кнопка «Вставить решение»

### Вкладка «Похожие заявки»
- 3 mock-карточки закрытых заявок: номер, описание, резолюция
- Кнопка «Клонировать решение»

### Вкладка «Чат»
- История сообщений (пользователь справа, бот слева)
- Анимированный индикатор печатания (3 точки)
- Отправка по Enter / кнопке «Отправить»
- Циклические mock-ответы бота

### Подвал (Footer)
- Кнопки обратной связи 👍 Полезно / 👎 Не полезно с визуальным состоянием
- Кнопка «Закрыть»

### Дизайн
- Нейтральная корпоративная палитра: белый фон, синий акцент `#2458e6`
- Чистые карточки с тенями, анимированный skeleton
- Чистый CSS без внешних фреймворков

## Этап 3 — Обновление до postMessage contract v1.0

**Основание:** новый спек из `ai.txt` с расширенным контрактом postMessage
и дополнительными требованиями к UI.

### postMessage контракт

| Направление | Тип события | Payload |
|---|---|---|
| SimpleOne → iframe | `copilot.handshake` | `record_id`, `table_name`, `csrf_token` |
| iframe → SimpleOne | `copilot.insert_solution` | `text` |
| iframe → SimpleOne | `copilot.close_modal` | — |
| iframe → SimpleOne | `copilot.link_ticket` | `related_record_id`, `related_number` |
| iframe → SimpleOne | `copilot.feedback` | `value`, `source_type`, `source_id` |

**Исправлено:** все `postMessage` теперь отправляются строго на
`simpleone_origin` из URL-параметра — убран небезопасный wildcard `'*'`.

### Шапка
- Добавлена подстрока с номером заявки (`number`) и темой (`subject`) из URL-параметров
- Кнопка «Суммировать заявку» получила spinner-анимацию на время «загрузки»

### Вкладка «Подсказки ИИ»
- Добавлены кнопки 👍/👎 на каждую карточку → отправляют `copilot.feedback`
  с `source_type: 'kb_article'` и `source_id`

### Вкладка «Похожие заявки»
- Текст резолюции сворачивается (первые 120 символов) с кнопкой «Показать полностью»
- Добавлена кнопка «Связать заявку» → отправляет `copilot.link_ticket`
- Добавлены кнопки 👍/👎 на каждую карточку

### Вкладка «Чат»
- Бот-сообщения получили аватар «AI» (синий круг)
- Под каждым ответом бота — кликабельные чипы-цитаты источников (KB-статья или номер заявки)

### Подвал
- Кнопка «Применено ✓» с активным состоянием (зелёный) после вставки решения
  → отправляет `copilot.feedback { value: 'applied' }`
- Заменены кнопки 👍/👎 на индикатор «ИИ доступен 🟢» / «ИИ недоступен 🔴»

### Автономный файл
- Обновлён `copilot-modal.html` — полностью самодостаточный файл (HTML + CSS + JS)
  без внешних зависимостей, реализует тот же контракт, пригоден для встраивания
  напрямую в SimpleOne Widget или UI Action без сборщика
